# Business case template

Fill every bracket from the interview. Delete any line the learner didn't
give you material for; never pad. The learner's own words go in quotes.
Nothing in brackets ships.

## Email (default, ~250 words)

```
Subject: [Course name] for [me / the design system team]: approval for $[total]

Hi [Manager],

I'd like to take [course name] ([url]), and I'm asking for $[total] from
[budget path].

Why now: [the pain, in the learner's words. One or two sentences. If an
inspection report exists: "Our design system inspection on [date] flagged
[n] items, including [the top red]. Chapter [n] of this course covers
exactly that."]

What it costs: $[price] per seat [× n seats, less the automatic 20% team
discount = $total], and about [n] hours a week for [n] weeks. It's
self-paced, so it fits around [the current project].

What you get back: by [date], I'll [the commitment from question 3:
"present the inspection work order to the team" / "propose a token
migration plan for [product]" / "run a lunch-and-learn on what we'd
change"]. [If seats > 1: "The [n] of us will each own one item from it."]

How to pay: [card, or "they issue invoices for procurement; I can request
one at courses@bradfrost.com" / "the quoted price holds for 45 days on an
invoice, so we can go through PO"].

If it turns out not to be useful, I'll say so, and we stop there.

Thanks,
[Name]
```

## Slack (~120 words)

```
Hey [Manager], a request: I'd like to take [course name] ([url]), $[total]
from [budget path].

Why: [one sentence of pain].
Cost: $[price][ × n, team discount applied] and ~[n] hrs/week for [n] weeks,
self-paced.
What you get: by [date] I'll [commitment].
Pay: [card / invoice via courses@bradfrost.com].

If it's not useful I'll say so and we stop. Ok to go ahead?
```

## One-pager (for a manager who forwards things)

```
# [Course name]: proposal

**Request:** $[total] from [budget path] for [n] seat(s).

**The problem**
[Two to four sentences, in the learner's words. Evidence lines from any
inspection report, with dates and station numbers.]

**What the course covers that we need**
- [Chapter or topic] → [our specific gap]
- [Chapter or topic] → [our specific gap]
(Two or three rows. Only the ones that map to a real gap.)

**Cost**
| | |
|---|---|
| Price per seat | $[price] |
| Seats | [n] |
| Team discount (3+) | [−20% / n/a] |
| Total | $[total] |
| Time | ~[n] hrs/week × [n] weeks, self-paced |

**What we get back, by [date]**
- [Commitment 1]
- [Commitment 2]

**How to pay:** [card / invoice via courses@bradfrost.com, price held 45 days]

**Risk:** If it isn't useful, [Name] says so and we stop at one seat.
```

## Before you send (the agent prints this after the draft, always)

- Confirm the price on the course page today. The draft used
  [the live page on <date> / the facts sheet, last verified <date>].
- Fill every bracket or delete the line.
- Don't add anything the draft doesn't already say. If it reads like an
  ad, cut the sentence.
- If you need an invoice or PO, email courses@bradfrost.com before you
  send this, so you can name the route.
